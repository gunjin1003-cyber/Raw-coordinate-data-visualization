# 연마량(Removal) 좌표 시각화

X·Y 좌표별 **연마량(removal amount)** 을 입력하면 **2D 맵**과 **3D 표면**으로 시각화해 주는
단일 HTML 파일입니다. 외부 라이브러리·인터넷 연결이 필요 없어 `index.html` 을 더블클릭하면 바로 열립니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| ① 좌표 · 연마량 데이터 | 표에서 좌표/값 직접 편집, 행 추가·삭제, 엑셀 붙여넣기, CSV·JSON 입출력 |
| ② 좌표 배치도 | 연마량과 무관하게 **입력된 좌표의 위치만** 확인하는 그림 (번호/좌표/값 라벨, 클릭으로 점 추가) |
| ③ 2D 연마량 맵 | 보간 채움 맵 · 등고 밴드 · 등고선 · 측정점 표시 |
| ④ 3D 표면 | 회전/확대 가능한 3D 표면 + 측정점 스템 |

## 좌표 관리 (범용성)

- 기본으로 253/240/218.8 … 형태의 **233점 좌표**가 들어 있습니다 (`기본 좌표(233점) 불러오기`).
- 어떤 좌표계든 쓸 수 있습니다. 사각 배열, 원형(웨이퍼) 배열, 불규칙 배열 모두 지원합니다.
  - **행 추가 / × 버튼** 으로 한 점씩 추가·삭제
  - **붙여넣기**: 엑셀에서 `X  Y  (연마량)` 열을 복사해 붙여넣기 → `적용`(교체) 또는 `기존에 추가`
    - 탭·쉼표·공백 구분 모두 인식하고, `X (mm)` 같은 머리글과 빈 줄은 자동으로 건너뜁니다.
  - **연마량만 붙여넣기**: 좌표는 그대로 두고 값 열만 표 순서대로 채웁니다.
  - **배치도에서 직접 편집**: `클릭 동작` 을 선택 / 점 추가 / 점 삭제 중에서 고릅니다.
    - `점 추가` — 캔버스 클릭으로 점 추가 (추가 스냅 간격 지정 가능)
    - `점 삭제` — 점을 클릭하면 즉시 삭제
    - 어떤 모드에서든 점을 **우클릭**하면 바로 삭제되고, 클릭으로 선택한 뒤 <kbd>Del</kbd> 키 또는
      `선택한 점 삭제` 버튼으로도 지울 수 있습니다.
    - `선택` 모드에서 점을 더블클릭하면 그 점의 연마량을 바로 입력합니다.
- **되돌리기**: 헤더의 `↩ 되돌리기` 또는 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 로 추가·삭제·붙여넣기·전체 삭제 등
  좌표를 바꾼 작업을 최근 30단계까지 취소할 수 있습니다.
- 값을 비워 두면 "값 없음"으로 처리되어 보간 계산에서 제외되고, 배치도에는 빈 원으로 표시됩니다.

## 보간 / 표시 옵션

- **보간 방식**: Linear(들로네 삼각분할, 권장) · IDW(거듭제곱 p, 이웃 수 k) · Nearest
- **영역 제한**: 볼록껍질(convex hull), 최근접 거리 한계, 또는 제한 없음 — 측정 영역 밖으로 색이 번지는 것을 막습니다.
- **색상**: Viridis / Turbo / Jet / Inferno / Coolwarm / RdYlBu / Grayscale, 반전 및 색 범위 수동 지정
- **단위**: µm, nm 등 자유 입력 (표 머리글·컬러바·툴팁에 반영)
- 요약 통계: 최소/최대/평균/σ/Range(P-V)/균일도 ±%

## 저장

- 작업 내용은 브라우저에 자동 저장되어 새로고침해도 유지됩니다.
- `프로젝트 저장(.json)` / `불러오기` (json·csv·txt), `CSV 내보내기`, 각 그림의 `PNG 저장`

## 조작

- 배치도: 클릭=모드별 동작, 우클릭=삭제, <kbd>Del</kbd>=선택 점 삭제, <kbd>Ctrl</kbd>+<kbd>Z</kbd>=되돌리기
- 2D·배치도: 마우스를 올리면 좌표·보간값·가장 가까운 측정점 정보 표시
- 3D: 드래그=회전, 휠=확대, `Shift`+드래그=이동, 등각/평면/정면/측면 프리셋
